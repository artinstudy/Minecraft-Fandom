# 🎮 Minecraft Fan Store & Portal Landing Page

A modern, fast, and fully responsive **Minecraft Fan Web Shop** landing page built entirely with semantic HTML5 and clean CSS3. This website template is designed for fan-made servers, communities, and marketplaces to showcase items and manage external social links.

## ✨ Features
* 🌐 **Fully Responsive:** Optimised for mobiles, tablets, and desktops.
* 🛒 **Store Display:** Clean item cards designed for showcasing ranks, items, or perks.
* 🔗 **Social Links Integration:** Quick-access links for Telegram channels, Discord servers, and YouTube.
* 👾 **Minecraft Aesthetic:** Uses classic pixelated typography and theme elements suitable for the gaming community.

## 🛠️ Tech Stack
* **HTML5** - Page structure and semantic layout.
* **CSS3** - Custom styling, flexbox/grid layout, and smooth animations.
